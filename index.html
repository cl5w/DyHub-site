Your Minecraft plugins,
in one workspace.

DyHub is a desktop application for organizing plugin releases, editing project content, and tracking download statistics across Modrinth, Hangar, CurseForge, and SpigotMC.

Release management

Prepare a JAR, version number, supported Minecraft versions, and changelog. Review the release before submitting it to supported platform APIs. SpigotMC publishing requires manual steps.

Download statistics

View total downloads and per-version statistics where the platform provides them, with the latest release highlighted.

CurseForge API usage

CurseForge read API access is used for project metadata, file information, and download statistics. Uploads use a separate author Upload API token. DyHub does not provide a third-party mod redistribution service. API access requires the user's own credentials and applicable platform permissions.

Local data

Project settings and release history are stored locally. Persisted API credentials use the operating system's encryption facilities. Backups exclude credentials.
